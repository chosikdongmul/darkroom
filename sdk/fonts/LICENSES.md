# 내장 글꼴 라이선스

Darkroom에 들어 있는 글꼴은 모두 **SIL Open Font License 1.1**입니다. 앱에 포함해 배포할 수 있고, 글꼴 자체를 따로 팔 수는 없습니다.
라이선스 전문은 `Pretendard-OFL.txt`의 본문과 같습니다(저작권 표시 줄만 서체마다 다름). 각 서체의 저작권은 해당 제작자에게 있습니다.

| 팩 (`packs/<key>`) | 서체 | 출처 |
|---|---|---|
| `pretendard` | Pretendard Variable v1.3.9 (동적 분할판) | github.com/orioncactus/pretendard |
| `gallery` | Instrument Serif, Hahmlet | Google Fonts |
| `lab` | IBM Plex Mono, IBM Plex Sans KR | Google Fonts |
| `magazine` | Fraunces, Gowun Batang | Google Fonts |
| `letterpress` | Cormorant Garamond, Song Myung | Google Fonts |
| `engraved` | Space Grotesk, Gothic A1 | Google Fonts |
| `credits` | Bodoni Moda, Nanum Myeongjo | Google Fonts |

Google Fonts 배포본은 css2 API가 나눠 주는 글자 범위별 조각(woff2)을 그대로 받아, 주소만 `https://assets.darkroom/fonts/packs/<key>/`로 바꿨습니다.
